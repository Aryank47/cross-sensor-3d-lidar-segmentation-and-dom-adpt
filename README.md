# cross-sensor-3d-lidar-segmentation-and-dom-adpt
This repo contains all the code related to my research on Cross-Sensor 3D LiDAR Segmentation &amp; DomAdpt where a model trained on ECLAIR, adapted to DALES using modern domain generalization (DG) and unsupervised domain adaptation (UDA) techniques, can recover a large fraction of the cross-dataset accuracy drop without requiring new labels.
